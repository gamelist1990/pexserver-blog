2026-11-20koukunn로컬 LLM GEEKOM eGPU 자작 PC 생성 AI

Mini PC에 중고 GPU를 외장으로 연결하니, 로컬 LLM이 실용 수준이 된 이야기 | GEEKOM A8＋AG02＋RTX 2080 SUPER 실측 기록

PRPEXServer 공식 포털자택 서버, 로컬 LLM, Minecraft 모드 개발 포털 사이트는 여기입니다

결론부터

  • 미니PC 「GEEKOM A8」에 eGPU 독 「AG02」와 중고 RTX 2080 SUPER를 외장 장착했다. 총액 63,200円
  • 로컬 LLM의 생성 속도는 최대 약116 tok/s이며, 현재 실제 운영 중인 모델에서는 **약113 tok/s（병렬3）**이다
  • 자신의 Discord Bot AI를 24시간 로컬에서 구동하는 용도로는 클라우드 API를 졸업할 수 있었다

"중고 GPU 외장 장착이 정말 실용적인가?"라는 의문에 실측으로 답하는 글입니다.

왜 했는가

Discord 서버에서 상주하는 AI Bot을 직접 제작하여 운영하고 있습니다. 처음에는 클라우드 API를 사용했지만,

  • 사용할수록 요금이 발생한다
  • 레이트 제한에 걸린다
  • 모델이나 파라미터를 자유롭게 시도할 수 없다

이러한 불만이 쌓였습니다. "어차피 상시 가동시킬 거라면, 내 컴퓨터에서 모델을 돌리고 싶다." 그래서 눈여겨본 것이 책상 위에 놓인 미니 PC, GEEKOM A8 이었습니다.

구매한 것

품목 가격 비고
Palit RTX 2080 SUPER X 8GB 28,800円 Amazon Renewed（정비 완료품）
AG02（eGPU독） 34,400円 USB4 / OCuLink 양쪽 대응
합계 63,200円

선정 포인트는 3가지입니다.

  1. NVIDIA 우선: 로컬 LLM 에코시스템은 CUDA 기반이 많은데, 트러블 발생 시 정보량이 차원이 다릅니다
  2. VRAM 8GB는 감수: 시도 목적이므로, 일단 작게 시작합니다
  3. 반품/보증 조건: 이 개체는 2027年1月末까지 반품 가능하며, 판매자 보증도 최소 180일입니다. 중고 GPU는 초기 불량이 두려우므로, "저렴함"보다 "문제가 생기면 되돌릴 수 있는 것"을 우선했습니다

GEEKOM A8 측 조건

  • CPU: Ryzen 7 8845HS
  • 메모리: 16GB × 1（DDR5-5600）※여유 슬롯 1
  • 연결: USB4(40Gbps)만 지원. OCuLink는 없음

OCuLink가 없기 때문에 대역폭은 USB4의 40Gbps가 상한입니다. 이 부분이 가장 불안 요소였지만, LLM 추론은 "모델을 VRAM에 올리면, 나머지는 GPU 내부에서 완결되는" 유형의 처리이므로, 실측 결과 치명적인 제약은 아니었습니다(후술).

설정에서 수행한 작업

  1. AG02에 2080 SUPER를 장착하고 USB4로 A8에 연결
  2. NVIDIA 드라이버 580.178.04 + CUDA 12.4.131을 도입
  3. llama.cpp를 CUDA 버전으로 빌드하여 추론
  4. 팬 제어: 헤드리스 환경에서는 GPU 팬이 돌지 않아 열로 인해 다운될 뻔했으므로, 고정 50%로 작동하는 상주 서비스를 직접 제작 → 73℃에서 안정

4번은 은근히 중요하며, 외장 GPU를 "서버처럼 무인으로 운영"하려면 온도 감시와 팬 제어는 가장 먼저 해결해야 할 포인트였습니다.

실측 결과

CUDA 버전 llama.cpp로 측정했습니다.

  • 생성 속도: 86.6 ~ 115.9 tok/s (모델 및 설정에 따라)
  • 프리필(입력 처리): 약 4,465 tok/s

현재 실제 Bot에서 사용하고 있는 구성은 다음과 같습니다.

  • 모델: Gemma 4 E4B
  • 생성 약 113 tok/s, 병렬 3 리퀘스트로 작동 중

챗봇 응답으로는 충분히 빠르며, 체감상 클라우드 API 시대와 비교해도 손색이 없습니다. 비용은 전기 요금뿐이 되었습니다.

시도해 본 것 중에서는 Gemma 4 12B (비QAT UD-Q3_K_XL 양자화)가 128K 컨텍스트 + MTP 활성화 시 약 54 tok/s로, 12B급으로는 상당히 쾌적했습니다. "8GB VRAM으로도 양자화와 모델 선택에 따라 여기까지 가능하다"는 것이 가장 큰 수확입니다.

걸리는 부분/주의사항

  • 메모리가 16GB × 1개 : 모델을 RAM에 캐시하는 사용법으로는 불안정합니다. 증설은 가격을 보고 보류 중입니다 (억지로 살 가격은 아닙니다)
  • A8의 NPU는 사용할 수 없습니다 : 칩에는 있지만 BIOS에서 비활성화되어 OS에서 보이지 않습니다. 활성화할 수 있더라도 현행 런타임 대상 외 세대이므로 LLM 용도로는 실질적으로 기대할 수 없습니다
  • 중고 GPU는 개체 차이 : 팬의 이상 소음이나 코일 떨림은 운입니다. 그렇기 때문에 반품 조건을 먼저 확인하는 것이 중요합니다

요약: 누구에게 적합한가

  • 적합한 사람: 상시 작동하는 자작 Bot이나, API 결제를 고정비(전기 요금)로 바꾸고 싶은 사람. 중고의 리스크 관리가 가능한 사람
  • 적합하지 않은 사람: 최신 대규모 모델을 최대 성능으로 구동하고 싶은 사람 (그것은 솔직히 새로운 GPU를 구매해야 함)

"미니PC + 중고 eGPU"라는 특이한 조합이지만, 총액 6만 엔 조금 넘는 비용으로 "자신의 AI 기반"을 갖출 수 있다는 것은, 실제로 해보니 상상 이상으로 쾌적했습니다.
